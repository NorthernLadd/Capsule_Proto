# As a user, I want to:

- Create my own profile, set my profile image and description, and see how many capsules I've found and created.
- Create a time capsule and place it at my current location.
- Create an account and log in so that my profile and capsules are saved between visits.
- Add a title, message, and photos to my capsule so that I can preserve a memory for someone to discover.
- Choose a future unlock date for my capsule so that its contents stay hidden until that date.
- View nearby capsules on a map so that I can discover capsules around me.
- See a capsule's title, distance from me, and unlock date before visiting its location so that I can plan which capsules to find.
- Open an unlocked capsule when I am near its location so that discovering it involves visiting the place where it was left.
- See how much time remains before a locked capsule opens so that I know when to return.
- Save capsules I want to visit so that I can find them again later.
- View a history of the capsules I've opened so that I can revisit their messages and photos.
- View and manage the capsules I've created so that I can keep track of their locations and unlock dates.
- Delete a capsule I've created if I no longer want to share it.
